# C++-based Clock 2026
This project was designed to be submitted to the 2026 MATH CLOCK CONTEST, hosted by YouTuber `Dr. Zye`. I created a mathematical puzzle clock incorporating computer science–based gimmicks. Please note that, as an undergraduate student, I may have included several inaccuracies.

## Environments
This project was implemented in the following environments. In particular, it was developed in `two different software environments`. However, strict compliance is not essential; as long as the environment is sufficiently modern, it is likely to work correctly. It is sufficient to have access to `Windows` and `Linux-based` operating systems.

### Software
  1. Windows 11, Visual Studio 2022, MSVC C++23, 64-bit, Release mode
  2. Ubuntu server 24.04.3 LTS, g++ 13.2.0, C++23, 64-bit, -Ofast
### Hardware
  - AMD Ryzen 7 5800X 8-Core Processor 3.8 Ghz

## Conditions
  1. Behavior not guaranteed by the C++ standard may be used as long as it does not cause errors.
  2. The use of libraries other than the C++ standard library is prohibited.
  3. In the `Software 1` environment, the program operates as a `24-hour clock`, while in the `Software 2` environment, it operates as a `12-hour clock`.

# C++ 기반 시계 2026
이 프로젝트는 유튜버 Dr. Zye가 개최한 2026 MATH CLOCK CONTEST에 제출하기 위해 기획되었다. 필자는 컴퓨터공학적 기믹을 이용한 수학 퍼즐 시계를 만들었다. 필자는 일개 학부생이기에 부정확한 설명이 다수 포함되어 있을 수 있음에 유의한다.

## 환경
해당 프로젝트는 다음과 같은 환경에서 구현되었다. 특히 `2가지 소프트웨어 환경`에서 구현되었다. 다만, 굳이 정확하게 준수하지 아니하여도 충분히 현대적인 환경이라면 정상 작동할 가능성이 크다. `윈도우`와 `리눅스 계열` 운영체제를 준비할 수 있다면 충분하다.

### 소프트웨어
  1. Windows 11, Visual Studio 2022, MSVC C++23, 64-bit, Release mode
  2. Ubuntu server 24.04.3 LTS, g++ 13.2.0, C++23, 64-bit, -Ofast
### 하드웨어
  - AMD Ryzen 7 5800X 8-Core Processor 3.8 Ghz

## 조건
  1. C++ 표준상으로 보장하지 않는 동작 또한 오류가 없다면 활용이 가능하다.
  2. C++ 표준 라이브러리 이외의 라이브러리 사용을 금한다.
  3. `소프트웨어 1`의 환경에서는 `24시간제 시계`로 동작하며 `소프트웨어 2`의 환경에서는 `12시간제 시계`로 동작한다.
